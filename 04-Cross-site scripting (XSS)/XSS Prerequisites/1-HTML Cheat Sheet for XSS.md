


## 1) هيكل الصفحة (Page Structure)

### 1- `<!DOCTYPE html>`

**الشرح:**  
يخبر المتصفح أن الصفحة تستخدم **HTML5** حتى يعرضها بالطريقة الصحيحة.

**مثال:**

```
<!DOCTYPE html>
```

---

### 2- `<html>`

**الشرح:**  
هو العنصر الأساسي (Root Element) الذي يحتوي على جميع عناصر صفحة HTML.

**مثال:**

```
<html>

</html>
```

---

### 3- `<head>`

**الشرح:**  
يحتوي على معلومات عن الصفحة لا تظهر للمستخدم، مثل عنوان الصفحة، وملفات CSS وJavaScript، وMeta Tags.

**مثال:**

```
<head>
    <title>My Website</title>
</head>
```

---

### 4- `<title>`

**الشرح:**  
يحدد عنوان الصفحة الذي يظهر في تبويب (Tab) المتصفح.

**مثال:**

```
<title>Home Page</title>
```

سيظهر أعلى المتصفح:

```
Home Page
```

---

### 5- `<body>`

**الشرح:**  
يحتوي على كل العناصر التي يراها المستخدم داخل الصفحة.

**مثال:**

```
<body>

<h1>Welcome</h1>

<p>Hello World</p>

</body>
```

---

# 2) عناصر النصوص (Text Elements)

---

### 1- `<h1>`

**الشرح:**  
أكبر عنوان في الصفحة ويستخدم للعناوين الرئيسية.

**مثال:**

```
<h1>Cyber Security</h1>
```

---

### 2- `<h2>`

**الشرح:**  
عنوان فرعي أقل حجمًا من `<h1>`.

**مثال:**

```
<h2>Introduction</h2>
```

---

### 3- `<h3>`

**الشرح:**  
عنوان فرعي أصغر من `<h2>`.

**مثال:**

```
<h3>What is XSS?</h3>
```

---

### 4- `<h4>`

**الشرح:**  
عنوان فرعي أصغر من `<h3>`.

**مثال:**

```
<h4>Reflected XSS</h4>
```

---

### 5- `<h5>`

**الشرح:**  
عنوان صغير.

**مثال:**

```
<h5>Example</h5>
```

---

### 6- `<h6>`

**الشرح:**  
أصغر عنوان في HTML.

**مثال:**

```
<h6>Note</h6>
```

---

### 7- `<p>`

**الشرح:**  
ينشئ فقرة نصية.

**مثال:**

```
<p>This is a paragraph.</p>
```

---

### 8- `<div>`

**الشرح:**  
عنصر عام يستخدم لتقسيم الصفحة إلى أقسام، ويعتبر **Block Element** (يبدأ في سطر جديد).

**مثال:**

```
<div>

Welcome to my website

</div>
```

---

### 9- `<span>`

**الشرح:**  
عنصر صغير يستخدم لتنسيق جزء معين من النص، ويعتبر **Inline Element** (يبقى في نفس السطر).

**مثال:**

```
<span style="color:red">
Danger
</span>
```

---

### 10- `<br>`

**الشرح:**  
ينقل المؤشر إلى سطر جديد بدون إنشاء فقرة جديدة.

**مثال:**

```
Hello

<br>

World
```

**الناتج:**

```
Hello
World
```

---

### 11- `<hr>`

**الشرح:**  
يرسم خطًا أفقيًا للفصل بين أجزاء الصفحة.

**مثال:**

```
<p>Chapter 1</p>

<hr>

<p>Chapter 2</p>
```

**الناتج:**

```
Chapter 1
-------------------------
Chapter 2
```

---
# 3) الروابط (Links)

---

## 1- `<a>`

**الشرح:**  
ينشئ رابطًا يمكن للمستخدم الضغط عليه للانتقال إلى صفحة أخرى أو موقع آخر.

**الصيغة:**

```
<a href="الرابط">النص</a>
```

**مثال:**

```
<a href="https://google.com">
Google
</a>
```

**الناتج:**  
عند الضغط على كلمة **Google** سيتم فتح الموقع.

**الأهمية في XSS:** ⭐⭐⭐⭐⭐

لأنه يستخدم خاصية `href`، وقد تظهر معه حالات تتعلق بـ `javascript:` في بعض البيئات أو التطبيقات الضعيفة.

# 4) الصور (Images)

---

## 1- `<img>`

**الشرح:**  
يعرض صورة داخل الصفحة.

**الصيغة:**

```
<img src="اسم الصورة">
```

**مثال:**

```
<img src="cat.jpg">
```

يعرض الصورة الموجودة باسم **cat.jpg**.

---

### إضافة نص بديل

```
<img src="cat.jpg" alt="Cat">
```

إذا لم يتم تحميل الصورة سيظهر النص:

```
Cat
```

---

### تحديد حجم الصورة

```
<img src="cat.jpg"
width="300"
height="200">
```

---

**الأهمية في XSS:** ⭐⭐⭐⭐⭐

لأن عنصر الصورة يدعم الحدث `onerror`، لذلك يُستخدم كثيرًا في مختبرات XSS التعليمية عندما يفشل تحميل الصورة.

</ul>

```

• JavaScript

**الأهمية في XSS:** ⭐⭐

# أشهر HTML Attributes

> **ما هو الـ Attribute؟**
> 
> الـ **Attribute** هو خاصية تضاف داخل الـ Tag لتغيير سلوكه أو إعطائه معلومات إضافية.
> 
> مثال:
> 
> ```
> <img src="cat.jpg" width="300">
> ```
> 
> هنا:
> 
> - `src` = Attribute
> - `width` = Attribute

---

# 1) id

**الشرح:**  
يعطي العنصر **معرفًا فريدًا** (Unique ID)، ولا يجب أن يتكرر داخل نفس الصفحة.

**الصيغة:**

```
id="اسم"
```

**مثال:**

```
<div id="header">
Welcome
</div>
```

**الاستخدام:**

JavaScript

```
document.getElementById("header")
```

CSS

```
#header{

color:red;

}
```

**الأهمية في XSS:** ⭐⭐⭐

---

# 2) class

**الشرح:**  
يجمع أكثر من عنصر داخل نفس المجموعة.

**الصيغة:**

```
class="اسم"
```

**مثال**

```
<p class="title">
Cyber Security
</p>
```

```

font-size:30px;

}

**الأهمية في XSS:** ⭐⭐
